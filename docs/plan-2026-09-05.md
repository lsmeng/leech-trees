## 4. 省 token 的执行协议

1. **分工**：Fable 只做推导、决策、论文文字、读结果页；Opus 做改代码+差分测试、成本评估、文献；
   Sonnet 做起跑/监控/收割/表格/短陈述反驳。
2. **每个 WP 一页 brief**：`docs/briefs/WP-xx.md` ≤60 行，给出精确文件与行号、输入、输出格式、
   验收、禁读清单。Agent 提示词 = "读 brief，按其执行"，不附任何对话历史。
3. **禁读**：agent 不读 `research_state.md`、`paper/main.tex`、THEORY.md 全文；只读 brief 点名的
   行段。需要背景时 brief 里给 5 行摘要。
4. **回传**：agent 只写 `docs/briefs/WP-xx-result.md` ≤60 行 + 固定键 JSON（status、numbers、
   hashes、blocking）。Fable 只读 result 文件，不读 agent 转录。
5. **一次一个**：同一时刻最多 2 个 agent；出错先看 result 里的 blocking 字段，不重跑。
6. **算力**：笔记本 ≤4 进程、`nice -n 15`、先 `pgrep -af`；>10 分钟的活全部上 geo-ws/Hoffman2；
   不动已有远程作业。
7. **预算估计**：Opus WP ≈ 150–300k token 各；Sonnet WP ≈ 30–80k 各；Fable 每个理论 WP 一个会话。
   全计划 agent 侧 ≈ 1.0–1.5M token。

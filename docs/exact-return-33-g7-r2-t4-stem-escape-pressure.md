# Stemmed-fork escape pressure control

This is a finite pressure control for one tempting step in Reflected-Owner
Reception.  It is **not** a Leech tree and proves no global exclusion.

## Statement

The following local data do not force the two cross distances generated by a
stemmed `q_B` fork to lie below the final bridge `s`.

Take the weighted tree with vertices

```text
g, u, v, x, p1, p2, y, z
```

and edges

```text
g-u=1,  g-x=2,  x-v=7,  v-p1=4,
v-p2=8,  u-y=19,  v-z=32.
```

Set `s=32`, the literal `v-z` edge.  At the cut `g-u`, put

```text
b0=d(g,x)=2,      r0=d(u,y)=19,
h=d(g,v)=9,       d1=d(v,p1)=4,       d2=d(v,p2)=8.
```

Then

```text
c=d(x,y)=22=s-10,
q_B=d1+d2=12=b0+10=(s-1)-r0,
q_R=d(v,y)=29=r0+10=(s-1)-b0.
```

Every one of the `binom(8,2)=28` pair distances is distinct.  The actual
owners of `q_B,q_R` are respectively `{p1,p2}` and `{v,y}`.  With the full
cut-side rooted sets

```text
B={0,2,9,13,17,41},       R={0,19},
```

the rooted holes hold:

```text
{q_B,q_B+4} intersection B = empty,
{q_R,q_R+4} intersection R = empty.
```

Nevertheless the two fork-generated cross distances are

```text
d(p1,y)=33>s,       d(p2,y)=37>s.
```

Thus no proof may apply punctured-low coverage to these two distances without
an additional upper-bound argument.  In particular, the identity
`D_i-s=h-d_j` alone does not give reflected-owner reception.

## Exact boundary

The control fails the actual Leech conditions: for order eight its cap is
`N=28`, whereas its maximum pair distance is `61`, and its pair-distance set
misses many low values (the first is `5`).  It also does not assert or check
the project-specific exact-return, least-remote, or final-bridge rooted-depth
support hypotheses.  It is therefore only a local pressure control.

The `D intersection (D+4)=empty` condition in this project is a condition on
a designated rooted-depth support, not a global ban on pair distances whose
values differ by four.  This control makes no claim about that support.

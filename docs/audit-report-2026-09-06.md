## Findings (most serious first)

**1. (major) `cor:secondend` (c): the statement is correct, but the printed proof has two genuine gaps.**
`paper/main.tex` L1618–1655. I re-derived (a) and (b) completely and tested all three parts against the four known trees with n ≥ 3 from Table 1 with an independent program (`audit/test_secondend.py`, written from the edge lists, not from project code): n = 3 (δ = 1, m = 2, x₀ ∈ W), n = 4 star (δ = 3, m = 3, x₀ ∈ W), n = 4 path (δ = 4, m = 2, x₀ ∈ W, the depth bound met with equality 5 = (11−1)/2), n = 6 (δ = 11, m = 4, x₀ ∉ W, the C(m+1,2) branch). The depth-bound algebra (C(m,2) ≤ 2N−1−2d(a,x₀), improving to C(m+1,2) when x₀ ∉ W) is correct, using distinctness of all distances and lca depth ≥ d(a,x₀). But:

- **Gap A (L1647–1648).** "A vertex of W on the path would be a common ancestor of all of W, hence equal to x₀" is a non sequitur: x₀ is the *last* common vertex of the paths, and a member of W sitting on the a–x₀ path is a common ancestor that need not a priori equal x₀. The conclusion (every path vertex other than x₀ lies outside W) is true — the n = 4 path and star realise x₀ ∈ W — but it needs the following argument. Suggested replacement: *"Suppose v ∈ W lies on the a–x₀ path. Then v lies on the a–u path for every u ∈ W, so d(v,u) = d(a,u) − d(a,v) for u ≠ v; positivity of these m−1 values forces d(a,v) = δ+1 and {d(v,u) : u ∈ W∖{v}} = {1,…,m−1}. Let u₁ be the member with d(v,u₁) = 1. If v ≠ x₀ then x₀ lies on the v–u₁ path beyond v, and d(v,x₀) ≤ d(v,u₁) = 1 forces x₀ = u₁ ∈ W with d(v,x₀) = 1. For m ≥ 3 the remaining m−2 members u′ satisfy d(x₀,u′) = d(v,u′)−1 ∈ {1,…,m−2}, and d(x₀,u′) ≠ 1 (a second weight-1 edge would duplicate the distance d(v,x₀) = 1); that is m−2 distinct values in the m−3 slots {2,…,m−2}, impossible. For m = 2, W = {v,b} and the a–b path passes through v, so x₀ = v. Hence every vertex of the a–x₀ path other than x₀ lies outside W."*
- **Gap B (L1648–1649).** "So … the edge bound follows." The run argument (two vertices outside W on the path are ≥ m apart) only covers edges whose *both* endpoints lie outside W. When x₀ ∈ W the last edge (x′,x₀) needs a separate word: then {d(x₀,u) : u ∈ W∖{x₀}} = {1,…,m−1}, and if w(x′x₀) < m this weight equals some d(x₀,u′), putting the distinct pairs {x′,x₀} and {x₀,u′} at the same distance — contradiction. One sentence suffices.

Neither gap affects the statement, the normal-form reading (s ≥ N−δ), or any number in the paper; the corollary is not cited by any theorem. But as printed the proof of (c) does not go through, and this is the newest load-bearing prose in the paper.

**2. (major) Route review §1.6, "Lemma 5": the unconditional bound is false — REFUTED; the paper's two-branch version is the correct one.**
